# Sentiment-Profiling-and-URL-Extraction-from-WhatsApp-Chats
Analyze your exported WhatsApp chat to uncover the emotional tone of conversations using **Natural Language Processing (NLP)**. This project performs **sentiment analysis** and **URL extraction** on WhatsApp chat data, providing meaningful insights through data visualization.

📌 Project Overview
This project aims to:
- Perform sentiment analysis on WhatsApp messages.
- Classify messages as **Positive**, **Neutral**, or **Negative**.
- Extract all shared URLs from the chat.
- Identify the most frequently shared links.
- Visualize sentiment distribution using graphs.
- Generate easy-to-understand insights from chat data.

This project is useful for exploring communication patterns, understanding conversation sentiment, and learning practical applications of NLP.

 ✨ Features
### 😊 Sentiment Analysis
- Detects the sentiment of each message using the **VADER Sentiment Analyzer**.
- Classifies messages into:
  - Positive
  - Neutral
  - Negative

### 📄 Chat Parsing
- Reads exported WhatsApp `.txt` chat files.
- Cleans and preprocesses messages before analysis.

### 🔗 URL Extraction
- Extracts all URLs shared in the conversation.
- Displays the most frequently shared links.

### 📊 Data Visualization
Generates visual insights including:
- Sentiment distribution chart
- URL frequency chart
- Additional analytics (if available)

### 📁 Clean Output
- Saves processed results and visualizations for easy review.

## ▶️ How to Run

### 1. Clone the repository
git clone https://github.com/your-username/whatsapp-sentiment-analysis.git
### 2. Navigate to the project folder
cd whatsapp-sentiment-analysis
### 3. Install the required packages
pip install -r requirements.txt
### 4. Export your WhatsApp chat
- Open a WhatsApp chat.
- Select **More → Export Chat**.
- Choose **Without Media**.
- Save the exported `.txt` file in the project folder.
### 5. Run the program
python sentiment_analysis.py
